# 复旦评教一键填写

Tampermonkey 用户脚本，在复旦大学教学质量管理平台 (ce.fudan.edu.cn) 上一键自动填写评教问卷。

## 功能

- 一键填写当前页面所有单选题和多选题
- 单选题：在「非常同意 / 同意 / 一般」之间按可调比例随机分配，避免被系统检测为「全部相同选项」
- 多选题：自动选择「无」
- 推荐类题目（如「是否会推荐本课程」）：自动跳过会触发必填理由框的选项，选择「一般」
- 自动关闭多教师课程弹出的「答卷提示」弹窗
- 不自动提交、不自动切换教师、不自动翻页，所有关键操作均由用户手动确认

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开 Tampermonkey → **创建新脚本**
3. 将 `fudan-evaluation.user.js` 的全部内容粘贴进去
4. `Ctrl+S` 保存，确保脚本开关为**启用**状态
5. 刷新评教页面，右下角应出现「评教助手」控制面板

## 使用

1. 打开评教页面（`https://ce.fudan.edu.cn` → 我的任务 → 评教）
2. 页面右下角出现控制面板
3. 调整比例（可选）：
   - **非常同意**：选「非常同意」的概率
   - **一般**：选「一般」的概率
   - **同意**：自动计算，保证三项之和为 100%
4. 点击 **一键填写**
5. 检查填写结果，手动点击提交
6. 手动切换到下一位教师或下一门课程，重复上述步骤

> 注意：如果三项比例之和超过 100%，「同意」会显示为负数（红色），按钮将被禁用。

## 隐私与安全

- 零权限：`@grant none`，不申请任何浏览器特权
- 零依赖：纯 JavaScript，无外部库
- 零网络请求：不向任何服务器发送数据
- 零持久化：不读取或写入任何本地存储
- 仅作用于评教页面：通过 URL 路径 `/my-task/answer/` 判断，其他页面仅注入空壳

可放心分享给同学使用，源码可自行审查。

## 适配范围

| 题型 | 支持 |
|------|------|
| 5 级 Likert 单选题 | 支持 |
| 多选题（带「无」选项） | 支持 |
| 条件输入框题（如推荐理由） | 支持 |
| 多教师课程弹窗 | 自动关闭 |
| 填空 / 矩阵量表 / 其他特殊题型 | 不支持 |

## 兼容性

选择器使用 `[class*="..."]` 属性匹配，不依赖 webpack CSS Module 生成的哈希后缀。平台常规版本更新不会导致脚本失效。

如果平台进行大规模重构或 Ant Design 升级至新大版本，可能需要适配。

## 故障排除

| 问题 | 解决方法 |
|------|---------|
| 控制面板不显示 | 打开 F12 Console，查找 `[评教脚本]` 日志；如果没有，检查 Tampermonkey 中脚本是否启用 |
| 点击按钮无反应 | 确认当前 URL 的 hash 中包含 `/my-task/answer/` |
| 提交时提示「全部选择的相同选项」 | 调整控制面板中的比例，避免所有题目选同一个答案 |

## 文件

- `fudan-evaluation.user.js` — Tampermonkey 用户脚本（安装此文件）
- `page.html` — 评教页面 DOM 参考（仅开发用）
- `docs/superpowers/specs/` — 设计文档

## 开发

如需适配新题型或修改选择策略：

1. `CONFIG.answerIndex`：单选题的基准选项索引（0 = 第一个，1 = 第二个）
2. `CONFIG.pctVeryAgree` / `CONFIG.pctNeutral`：随机分布的默认比例
3. `fillCurrentPage()`：核心填写逻辑，分单选题和多选题两条路径
4. `dismissTipDialog()`：弹窗关闭逻辑

选择器策略：对平台自定义类名使用 `[class*="xxx"]` 模糊匹配，对 Ant Design 组件使用稳定类名（如 `.ant-radio-group`、`label.ant-radio-wrapper`），对按钮使用文本内容匹配。
